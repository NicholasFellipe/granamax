## 🎯 PRÓXIMOS 3 PASSOS (HOJE)

### PASSO 1: Escolher Como Salvar Dados (5-30 minutos)

Você tem 2 opções:

**Opção A: LocalStorage (Mais Rápido - 5 min)** 🟢 RECOMENDADO PARA COMEÇAR
- ✅ 100% grátis
- ✅ Zero configuração
- ✅ Funciona imediatamente
- ❌ Dados só no seu navegador
- 📄 Siga: `ALTERNATIVA_LOCALSTORAGE.md`

**Opção B: Firebase (Cloud - 30 min)**
- ✅ Dados sincronizados
- ✅ Múltiplos usuários
- ✅ Escala automaticamente
- 📄 Configuração abaixo

**Firebase (se escolher Opção B):**
1. Vá em https://console.firebase.google.com/
2. Crie projeto "GranaMax"
3. Ative Authentication (Email/Password)
4. Crie banco Firestore
5. Cole credenciais em `src/config/firebase.ts`

> 💡 **Recomendação:** Comece com LocalStorage hoje, migre para Firebase se decidir lançar!

### PASSO 2: Rodar o App (10 minutos)

```bash
npm install
npm run dev
```

Abra http://localhost:5173 e teste:
